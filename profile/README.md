## 🚀 Overview
DNS Changer for Windows is a simple tool for switching the DNS servers your PC uses and finding the fastest option. Instead of digging through network settings, you pick from a list of popular public DNS providers or enter your own, then apply the change with one click. A built-in speed test measures response times so you can choose the DNS that loads pages quickest on your connection. Whether you want snappier browsing, more reliable lookups, or an easy way to revert, this DNS changer keeps everything in one clean window.

## ✨ Features
- **One-click DNS switching** — Change your DNS servers instantly and revert to automatic just as easily.
- **DNS speed test** — Measure and compare response times to find the fastest DNS for your connection.
- **Ready-made presets** — Choose from popular public DNS providers or add custom addresses.
- **Per-adapter control** — Apply DNS to a specific network adapter or all of them at once.
- **Cache flush** — Clear the DNS cache in a click to apply changes cleanly.

## ❓ FAQ
**What is a DNS changer?**
A DNS changer is a tool that lets you swap the DNS servers your PC uses to look up websites. Choosing a faster or more reliable DNS can speed up browsing and improve stability.

**Is DNS Changer malware?**
No. This app is a legitimate DNS changer that simply updates your own network settings on your PC; it is unrelated to the old DNS-hijacking malware of a similar name and never changes your DNS without your action.

**Which versions of Windows are supported?**
It runs on modern 64-bit Windows, including Windows 10 and Windows 11. Installing the latest stable release is recommended.
